# Raphael G. U. Eriemo — Personal Website

Source code for Raphael Eriemo's personal brand website at `raphdegreat.com`.

The site presents Raphael's work in HealthTech first, followed by property development, renovation, business strategy, operations leadership, and the wider founder journey behind Maluel Limited, Ornia, and Marvel Homes.

## Technology

- React 19
- Next.js 16
- TypeScript
- Tailwind CSS

Node.js 22 or later is recommended.

## Run locally

```bash
npm install
npm run dev
```

Then open the local address shown in the terminal.

## Production build

```bash
npm run build
```

## Main content files

- `app/page.tsx` — page content and structure
- `app/globals.css` — visual styling and responsive layout
- `app/layout.tsx` — metadata and document layout
- `public/portraits/` — approved portraits used on the website

## Deployment

The project can be deployed through any hosting service that supports Next.js. A separate static production archive is maintained for conventional hosting where files are uploaded directly into a web root such as `public_html`.

HealthTech statements must continue to describe Ornia as a product in development. Do not add claims of clinical validation, regulatory approval, proven medical outcomes, market adoption, hospital endorsement, or granted patents without current supporting evidence.

## Brand direction

- HealthTech before real estate
- Black and champagne-gold luxury palette
- Direct, evidence-led language
- High-value solutions presented with restraint and credibility
